OLIVER J. RAMOS — DIGITAL PORTFOLIO
====================================

This is a static HTML/CSS/JavaScript portfolio. It does not require a database, Node.js server, or build command. It is ready for GitHub Pages, Netlify, or Vercel static deployment.

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in your browser.
   (For the best local preview, use the VS Code extension "Live Server".)

HOW TO CHANGE THE PICTURES
All placeholder images are in:
  assets/images/

Replace a placeholder image with your own image and keep the same filename, OR update the relevant image src in index.html to your new filename.

Picture filenames:
- profile-placeholder.svg                 = profile picture
- project-grading-placeholder.svg         = Grading System project
- project-pos-placeholder.svg              = POS Grocery Store project
- project-os-placeholder.svg               = OS Installation project
- certificate-devcon-sui-placeholder.svg    = DEVCON_SUI certificate
- certificate-devcon-robotics-placeholder.svg = DEVCON_Robotics certificate
- certificate-gameplay-placeholder.svg     = Gameplay_Defence certificate
- certificate-cisco-placeholder.svg        = Getting Started in Cisco Packet Tracer certificate

Recommended: use JPG, PNG, or WebP for your actual photos/scans. If you use a different filename, change the matching src in index.html.

EDIT YOUR DETAILS
- Main content and descriptions: index.html
- Colors, layout, typography, responsive design: styles.css
- Typing animation and mobile menu: script.js
- Contact email: replace oliver.ramos@example.com in index.html with your real email address.

DEPLOY TO VERCEL (STATIC)
1. Extract the ZIP.
2. Upload the contents of the oliver_ramos_portfolio folder to a GitHub repository (index.html should be in the repository root).
3. In Vercel, choose Add New > Project and import that repository.
4. Framework Preset: Other.
5. Build Command: leave blank.
6. Output Directory: leave blank or set to . if prompted.
7. Deploy.

IMPORTANT
The image files are illustrative placeholders. Replace them with your own pictures/certificate scans before publishing. Update the example email address before sharing the site publicly.
